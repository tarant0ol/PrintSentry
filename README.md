# PrintSentry - система контроля качества и мониторинга

PrintSentry - подсистема контроля качества и мониторинга для полигона фотополимерной 3D печати. 
Стек: Python, Streamlit, SQLAlchemy, PostgreSQL.

## 1. Что реализовано

- база данных на Postgresql
- миграция таблиц из базы данных в `models.py`.
- подключение к базе данных и получение первых данных
- созданы 5 вкладок, каждая с собственным функционалом
